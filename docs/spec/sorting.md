# 排序规则

## 排序语义

- 加好友时间：恢复网页默认顺序，即从旧到新。
- 名称：按访问者浏览器语言对展示名称自然升序排列，忽略大小写；也可切换为降序，同名时保留排序前的相对顺序。
- 上次活跃：按默认时间胶囊全部动态中第一条动态的活跃时刻从近到远排列，也可从旧到新排列。活跃时刻的解析与精度规则见[上次活跃与时间胶囊](data.md#上次活跃与时间胶囊)。
- 和我贴贴：按当前登录访问者收到的贴贴数量从多到少排列，也可从少到多排列；统计范围、反应者和去重规则见[和我贴贴数据](data.md#和我贴贴数据)。
- 同步率：按当前登录访问者与好友的同步率排序；共同喜好数：按当前登录访问者与好友的共同喜好条目数量排序。两者均要求登录，并按访问者标识隔离数据，数据定义与缓存见[用户主页字段与缓存](data.md#用户主页字段与缓存)。
- 完成条目数：按全部、动画、书籍、音乐、游戏或三次元范围内状态为“完成”的条目数量排序；“全部”是默认范围。
- 完成条目数默认从高到低，方向文案为“从低到高”与“从高到低”。数值相同时保持排序前的相对顺序；未知值在两个方向均排在可靠值之后；明确取得的 `0` 是可靠值。
- 同步率和共同喜好数默认从高到低。
- 每次进入页面默认使用加好友时间的从旧到新。各主排序按钮在当前页面内分别记忆上次选择的方向，但不持久化排序选择或方向。

## 平局继承排序前顺序

本节记录当前实现的平局规则。

- 每次重排以当前页面内紧邻此前的完整好友顺序为基础。主排序值相同时保留该相对顺序；连续切换排序可自然保留更早排序形成的平局次序，不重新计算上一个排序字段。
- 适用于名称、上次活跃、喜好契合的两个指标及完成条目数的全部统计范围。名称相同时自然比较结果为平局，保留排序前顺序，不再使用用户标识作为次键。
- 切换升降序只改变主排序值的方向，不翻转平局组。例如降序 `A(10)、B(10)、C(5)` 切为升序后是 `C(5)、A(10)、B(10)`。
- 远程目标先按缓存重排，再在刷新完成后重排；后者继承缓存阶段已经展示的顺序。例如切换前为 A、B，缓存重排为 B、A，刷新后数值相同则保持 B、A。
- 无可靠数值仍在两个方向均排在可靠值之后，组内保持排序前顺序；上次活跃中的无公开动态与未知活跃时间沿用现有末尾分组，组内继承排序前顺序。相同活跃时刻也继承排序前顺序。明确取得的零仍为可靠数值。
- 顺序仅在当前页面内保留。首次进入以网页默认顺序为起点；重新打开或刷新页面后重新起算，不跨页面保存排序历史。
- 隐藏好友仍参与排序；筛选只改变可见性与名次。名次始终按当前可见顺序从 1 连续编号，呈现规则见[页面与排序栏](ui.md#页面与排序栏)。
- “加好友时间 → 从旧到新”仍恢复网页默认顺序，并成为下一次排序的基础；从新到旧仍按网页默认顺序反向排列。
- 当前好友集合在初始化时一次性读取，本次不扩展动态新增好友支持；纯状态提示不触发重排。
