# 和我贴贴对无内容链接动态的逐级去重

时间胶囊中的签名更新等动态可以包含贴贴数据，却不提供内容链接。此前解析器把这类动态判为页面残缺，导致包含它的整页失败，完整统计无法发布；直接忽略它们又会漏计用户实际收到的贴贴。

我们决定：统计每条动态时，依次使用内容链接、动态编号、表情容器完整标识去重。一个动态同时提供多个标识时，登记它们之间的关联，使后续缺少高优先级标识的同一动态仍能合并。两个条目具有不同内容链接时，内容链接优先，不能仅凭相同的动态编号或表情容器标识合并；动态编号和表情容器标识也属于不同来源，不能仅因值相同而合并。三个标识都没有时，不去重，直接累计该条动态的反应者。

没有内容链接本身不再是解析失败。没有反应容器标识、反应数据结构损坏或反应者无法解析仍视为页面失败；有效的空反应容器没有数据条目时表示该动态目前没有贴贴，按可靠零处理。原站同一用户不能在同一条动态上贴多个表情，因此一条动态内的反应者仍按用户去重一次。

被拒的备选：忽略所有没有内容链接的动态——会漏计签名更新等动态中的真实贴贴；为无链接动态猜测内容名称——名称不稳定且可能相同；只用动态编号或表情容器标识——这些标识在不同条目类型和响应结构中可能缺失或来源不同。

后果：完整结果的 72 小时缓存策略不变；修复后的下一次成功获取会纳入此前漏计的反应，失败批次仍不会覆盖旧缓存。没有任何标识的重复动态无法安全识别，按决定会重复累计。
