# 在原更新地址生成可读单文件

旧安装与更新 URL 直接指向 `src/index.user.js`，审核也要求完整可读的单文件。选择将该文件保留为受版本控制的 Rollup IIFE 产物，以 `src/main.mjs` 为唯一浏览器入口、`src/metadata.txt` 为人工管理的模板、package 版本为版本值来源；用 Prettier 格式化并以只读重新生成比较阻止漏构建。比起移动发布地址、运行时加载模块或继续手改交付物，这一方案保留现有安装契约而允许随后按职责拆分源码；职责拆分后已删除过渡模块 `src/legacy.mjs`，维护源按 `docs/module-guide.md` 导航；普通说明性注释与模块来源注释由构建保留在产物中。构建不发布、不升级版本，也不改变其他元数据字段。
