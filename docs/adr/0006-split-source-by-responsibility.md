# 按职责拆分维护源

过渡期的 `src/legacy.mjs` 集中承担解析、缓存、调度、交互与页面装配，查找改动和测试导入都依赖同一大模块。现在将已有函数按依赖方向移至 `docs/module-guide.md` 所列 ESM 源文件，删除过渡文件和聚合测试出口。入口只负责页面装配；会话仍持有排序与远程任务的私有状态，缓存、调度、状态控制器、排序栏仍各为实例；排序栏独自持有并观察 DOM。配置与标识位于依赖链下层，任务使用刷新生命周期桥接缓存、调度和提示，不使用全局事件总线或循环依赖。

测试按职责导入现有公开接口，另以生成的脚本在浏览器环境检验自动启动、真实 HTML 解析、缓存写入、排序及可见名次。原单文件发布地址、人工管理元数据、Rollup IIFE/Prettier 选项和缓存格式不变；源码顶部的路径说明与已有领域注释在产物中可辨认。选择保留现有工厂与任务接口而不按文件大小切片，以避免无关业务重设计。
